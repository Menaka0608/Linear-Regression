# Linear Regression

This project demonstrates a Linear Regression model using Python and Jupyter Notebook.

## Project Overview

The project uses Linear Regression to understand the relationship between input and target variables and make numerical predictions.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm

Linear Regression

## Project Workflow

1. Load the dataset
2. Explore and preprocess the data
3. Split the data into training and testing sets
4. Train the Linear Regression model
5. Make predictions
6. Evaluate the model
7. Visualize the results
